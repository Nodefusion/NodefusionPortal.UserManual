# About

The About page shows which version of the portal you are using and links to help. Every user can open it.

## Version information

- **Environment**: the environment the portal runs in.
- **Application**: the name of the web application.
- **Web app version**: the version of the portal in your browser.
- **API version**: the version of the service behind the portal. It shows `unknown` if it cannot be read.

Support may ask for these versions when you report a problem. Select **Copy version info** to copy all four values to the clipboard.

## Help

- **Nodefusion Portal User Manual**: opens this manual in a new tab.
- **Send feedback**: opens the [Feedback](Organizations/Feedback.md) page. It is shown only when you open About from within an organization, and not to the Support user.

## Notifications

After you select **Copy version info**, a message says "Version info copied". If the browser does not allow copying, the message is "Could not copy to the clipboard".
