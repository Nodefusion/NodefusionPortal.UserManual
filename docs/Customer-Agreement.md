# Customer Agreement

An organization can only be used in the portal after it has accepted the latest version of the **Nodefusion Customer Agreement**. Until then, the organization is marked **Customer agreement required** in the organization list and in the organization menu.

When you open such an organization, the **Nodefusion Customer Agreement** dialog appears over the current page. The dialog cannot be closed with the Escape key or by clicking outside it. You can leave it only by accepting the agreement or by selecting **Choose another organization**.

The dialog contains the message that your organization did not accept the latest version of the agreement and the link **Read the Nodefusion Customer Agreement**, which opens the agreement in a new browser tab.

## If you have Full access

Fill in the form:

- **First name\***
- **Last name\***
- **Contact email\***
- **Contact phone**
- **I accept the Nodefusion Customer Agreement\*** (check box)

Then select **Accept agreement**. The organization's Home page opens. If the agreement cannot be saved, the dialog shows "The agreement could not be saved. Please try again." and stays open.

## If you have another access level

Only a user with Full access can accept the agreement. The dialog tells you that a user with Full access has to accept it before you can continue. Ask that person to open the organization and accept the agreement.

## Choose another organization

**Choose another organization** closes the dialog. You stay on the page where you were.
