# New Microsoft tenant

Use this form to create a new Microsoft cloud tenant for your organization. It requires the Manage level or Full access. Open it with **Add a Microsoft tenant** on the [Microsoft](index.md) page. Fields marked with `*` are required.

## Form

The form has these cards:

- **Tenant domain**: `Domain*`, the subdomain of the new tenant, followed by `.onmicrosoft.com`. Enter only the subdomain (for example `contoso`). It cannot be changed after the tenant is created.
- **Company**: `Company name*`, `Address*`, `City*`, `Postal code*`, `State or county*` and `Country`.
- **Language**: `Culture` and `Language`. Choosing a country also sets the culture (Croatia sets hr-HR, any other country sets en-US).
- **Tenant administrator**: `First name*`, `Last name*`, `Email*` and `Phone number*`.

The **Region** card on the side shows the region, which is set automatically from the country. Follow its link to read about Microsoft regional authorization.

If a field is missing or invalid, a message explains what to correct. See the forms section of [Getting Started](../../../index.md).

## Create the tenant

Select **Create tenant** to create the tenant, or **Cancel** to return to the [Microsoft](index.md) page.

The result appears on the same page in an **Information** box. It contains the username and password of the tenant administrator account and asks you to sign in at the Microsoft admin center and change the password. If something went wrong, the box instead tells you to contact Nodefusion customer care and gives a correlation ID. Save the information from the box before leaving the page.

## Notifications

After the tenant is created, a success message is shown. If creating the tenant fails, an error message is shown and the form stays filled in.
