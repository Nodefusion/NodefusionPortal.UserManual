# Add subscription

Use this page to request a new Microsoft subscription in a tenant. It requires the Manage level or Full access. Open it with **Add subscription** on a tenant card on the [Microsoft](index.md) page. The page subtitle names the tenant the subscription is added to.

:::note
Loading the available products can take several minutes.
:::

To avoid loading the same data again and again, the portal keeps loaded data on your computer for 5 minutes. When cached data is shown, a line "Showing cached data, loaded ..." appears at the top of the page; select **Refresh** in that line to load fresh data.

## Choose a product

In one card, select the kind of product:

- **Online services**
- **Software subscriptions**
- **Perpetual software**

Then search by name or product ID, and move between pages of the list. Each product has a **Configure** button.

## Configure and send

**Configure** replaces the product row with a form:

- **Plan**: the plan of the product.
- **Term**: choose a term. If the plan has only one, it is shown with the note "Only term available for this plan." Perpetual software has no term.
- **Quantity**: the number of licences, within the limits of the plan.

Select **Send create request** to send the request to Nodefusion. The subscription is not created immediately; it is created after Nodefusion processes the request. Select **Close** to put the product row back without sending.

If a product cannot be ordered in the chosen kind, the form shows a message starting with "Microsoft error", for example that the software has no subscription plan, or is not perpetual. The message tells you which kind to check instead.

A new subscription appears on the [Microsoft](index.md) page after it is processed, which can take up to 1 hour.

## Notifications

After you send a request, a message tells you that the creation request was submitted. The subscription is not created yet: Nodefusion handles the request first, and the subscription appears in the list afterwards. If sending fails, an error message is shown and the form stays open.
