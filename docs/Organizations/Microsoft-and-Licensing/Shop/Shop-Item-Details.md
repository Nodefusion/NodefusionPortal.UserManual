# Purchase request details

This page shows a sent purchase request. Open it by selecting a request on the [Shop](index.md) page. The page is read-only and has no buttons.

It shows:

- **Description**
- **Expected start**
- **Expected close** ("Not set" when empty)
- **Contact** ("Not set" when empty)

The title and the date range are shown at the top.
