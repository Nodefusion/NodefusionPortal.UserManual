# Shop

The Shop page lists your organization's purchase requests. It is available with the Read level or higher. Open and won requests are listed; lost ones are not.

If something is not working, a bar at the top has a **New case** button to report it as a case instead (see [Cases](../../Support/Cases/index.md)). It is shown to users who can create cases.

## List

The list shows the number of requests and has a search field (name or contact), sorting and paging. Columns:

- **Request**
- **Contact**
- **Expected start**
- **Expected close**

The list is sorted by Expected start, latest first. Select a request to open its [details](Shop-Item-Details.md). Empty values are shown as a dash.

## New purchase request

**New purchase request** opens the [form](Create-Shop-Item.md) for a new request. See [Getting Started](../../../index.md) for how lists work in general.

## Fresh data

The portal keeps the loaded list on your computer for 5 minutes. The **Refresh** button in the toolbar above the list loads fresh data.

## Notifications

When the list cannot be loaded, an error is shown with a retry option. Messages about sending a request appear on the [New purchase request](Create-Shop-Item.md) page.
