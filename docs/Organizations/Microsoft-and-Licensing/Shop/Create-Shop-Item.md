# New purchase request

Use this form to ask Nodefusion for an offer. The request is sent to Nodefusion and is not carried out immediately. Open it with **New purchase request** on the [Shop](index.md) page. Fields marked with `*` are required.

## Form

- **What do you need?**: `Title*`, `Description*` (products, licences or services, and any requirements) and `Quantity` (from 1 to 1,000,000, default 1).
- **Timing**: `Expected order date*` and `Expected delivery date*`. Approximate dates are enough.
- **Contact**: `Authorized contact email*`, the person who can approve the offer. It is prefilled with your email. Tip: you can use a contact from [Organization Profile, Contacts](../../Organization/Organization-Profile.md#contacts).

The **Good to know** card links to the Microsoft page for adding or changing Microsoft subscriptions and, for users who can create cases, to reporting a problem as a case instead.

If a field is missing or invalid, a message explains what to correct. See the forms section of [Getting Started](../../../index.md).

## Send

Select **Send purchase request** to send it, or **Cancel** to go back to the [Shop](index.md) page.

## Notifications

After you send the request, a message tells you that the purchase request was sent and that Nodefusion will review it, and you return to the Shop list. Nothing is ordered yet: Nodefusion handles the request first. If sending fails, an error message is shown and the form stays filled in.
