# Home

Home is the first page of an organization. The page title is the organization name, and below it the line "Your access level in this organization is ..." shows your [access level](Permissions.md#access-levels). Each card summarizes one area; **View all** opens the full page.

## Cards

- **Cases**: counts of **Open** cases and cases **Waiting for you** (cases from the last 6 months) and the latest open cases. Select a count to open the case list with that filter, or a case to open it. **New case** starts a new case, see [Create a case](../Support/Cases/Case-Create.md).
- **Shop**: the latest purchase requests with their expected dates and contact. **New request** starts a new Shop request.
- **Other subscriptions**: subscriptions that are not Microsoft subscriptions, with quantity and end date.
- **Domains**: expired domains first, then those expiring soon, then active ones.
- **Crohoster**: hosting accounts with plan and expiry.
- **Roadmap**: active initiatives, shown as a **List** or a **Timeline** (the timeline is not available on a phone).

## Access levels

- **Full access**, **Manage** and **Read** see all cards and can use **New request**. **New case** is shown to Full access and Manage, but not to Read.
- **Write** sees only a message and the **New case** button.
- **Support user** sees only the Cases card, with **New case**.

See [Permissions](Permissions.md#access-levels) for the complete overview.

## Cached data

The portal keeps the loaded data on your computer for 5 minutes so it does not have to be fetched every time. When some of the data comes from this stored copy, the line "Showing cached data, loaded ..." appears above the cards; select **Refresh** in it to load fresh data. See also [Getting Started](../../index.md#cached-data).

## Notifications

Home only shows data and has no actions of its own. If a card cannot load, it shows an error message with **Try again**.
