# Crohoster

Nodefusion uses Crohoster for web hosting and domains. The Crohoster page lists the hosting accounts of your organization, their plans and when they expire. To compare plans and prices, visit [www.crohoster.com](https://www.crohoster.com).

You need at least the Read access level to open this page. Requesting an account needs Manage or Full access.

## Account list

The list has four columns:

- **Account**: the account name, with its primary domain below it.
- **Plan**: the hosting plan.
- **Status**: the status of the account.
- **Expires**: the expiry date.

Use the search field to find an account by name, domain, plan or status, and **Sort by** to change the order. For lists and search, see [Getting Started](../../index.md).

The portal keeps the loaded list on your computer for 5 minutes, so it does not have to be fetched every time you open the page. To load fresh data, use the refresh button at the start of the toolbar.

## Request an account

1. Select **Request account**.
2. In the **Request a hosting account** dialog, choose a **Plan**\* (A, B, C or D). Select **Compare plans on crohoster.com** to see the plans in a new tab.
3. Select **Send account request**.

The request is sent to Nodefusion and is not carried out immediately. The account list does not change until then.

## Notifications

- After the request is sent, the message "Hosting account request sent. Nodefusion will review it." appears. The account is not created yet and does not appear in the list until Nodefusion handles the request.
- If sending fails, an error message appears. The dialog stays open so you can try again.
- If the list cannot be loaded, an error message with **Try again** appears in place of the list.
