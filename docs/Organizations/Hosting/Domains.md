# Domains

The Domains page lists the domains registered for your organization and shows when they expire. Nodefusion uses Crohoster to register domains.

You need at least the Read access level to open this page. Requesting a new domain needs Manage or Full access.

## Domain list

The list is sorted by expiry date, soonest first, and has three columns:

- **Domain**: the domain name.
- **Status**: `Expired` once the expiry date has passed, `Expires in N days` when it expires within 60 days, otherwise `Active`.
- **Expires**: the expiry date.

Use the search field to find a domain by name or status, and **Sort by** to change the order. For lists and search, see [Getting Started](../../index.md).

The portal keeps the loaded list on your computer for 5 minutes, so it does not have to be fetched every time you open the page. To load fresh data, use the refresh button at the start of the toolbar.

## Request a domain

1. Select **Request domain**.
2. In the **Request a new domain** dialog, enter the **Domain name**\* (for example `example.hr`).
3. Select **Request domain registration**.

The request is sent to Nodefusion and is not carried out immediately. The domain list does not change until then.

If the domain name is missing or not in a valid format, the dialog shows "Enter a domain such as example.hr."

## Notifications

- After the request is sent, the message "Domain request sent. Nodefusion will review it." appears. The domain is not registered yet and does not appear in the list until Nodefusion handles the request.
- If sending fails, an error message appears. The dialog stays open so you can try again.
- If the list cannot be loaded, an error message with **Try again** appears in place of the list.
