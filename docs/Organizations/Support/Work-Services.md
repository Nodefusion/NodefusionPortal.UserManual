# Work Services

The Work Services page shows the hours used within your work service, the cases of the current period and the history of work reports. Viewing the page needs the access level Full access, Manage or Read.

If your organization has no work service, the page shows **No active work service found.**

## Estimated hours

A card for each work service shows:

- **Estimated** label with the hours worked this period so far. The number is an estimate and can differ from the hours on the final work report.
- **Included hours**: hours included in your work service.
- **Current period**: start and end date of the billing period that includes today.

## Cases

The Cases card next to it counts the cases created in the current period: **Open** (includes the ones waiting for you), **Waiting for you**, **Closed** and **All**. Select a count to open the [Cases](Cases/index.md) page with that filter.

- **New case** opens the [new case form](Cases/Case-Create.md). It is shown only if your access level allows creating cases.
- **View all** opens the [Cases](Cases/index.md) list.

## Work reports

The table lists issued work reports:

| Column | Content |
| --- | --- |
| **Billing period** | Period the report covers |
| **Issued** | Date the report was issued |
| **Report** | File name; select it to download the report as a PDF |

The latest billing period is shown first. Use **Search billing period or file** to narrow the list, select a heading to sort, and use the pager below the table to change the page or the number of rows. If there are no reports yet, the page says so.

## Cached data

The portal keeps the loaded data on your computer for 5 minutes, so it does not have to be fetched every time. When some of it comes from this stored copy, the line **Showing cached data, loaded ...** appears above the cards. Select **Refresh** in that line to load fresh data. See also [Cached data](../../index.md#cached-data) in Getting Started.

## Notifications

This page only shows data. If loading fails, an error message with **Try again** appears in place of the affected card or table. A report that cannot be downloaded shows an error message. See [Messages and notifications](../../index.md#messages-and-notifications).
