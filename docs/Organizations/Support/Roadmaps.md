# Roadmaps

The Roadmaps page shows the initiatives that Nodefusion has planned for your organization. Viewing it needs the access level Full access, Manage or Read.

Active initiatives are listed first, then postponed ones, each by start date. If nothing is planned, the page says **There are no planned initiatives.**

## List view

The List view is the default. Its columns are **Initiative**, **Status** (Active or Postponed), **Contact**, **Expected start** and **Expected close**. Select a column heading to sort by it. Use **Search name, status or contact** to narrow the list.

## Timeline view

Switch to **Timeline** with the toggle at the top right of the card. Each initiative is a bar on a monthly scale, from its expected start to its expected close, and a line marks today. Scroll sideways to see further months. Search and sorting apply to the List view only.

On a narrow screen only the list is available.

## Cached data

The portal keeps the loaded roadmap on your computer for 5 minutes, so it does not have to be fetched every time. When the data comes from this stored copy, a refresh button appears at the start of the toolbar; its tooltip shows when the data was loaded. Select it to load fresh data. See also [Cached data](../../index.md#cached-data) in Getting Started.

This page only shows data and sends nothing. If loading fails, an error message with **Try again** is shown in place of the list.
